# Surebet Scanner — 1xBet × Olimp

Сканер живых вилок (surebets) по **тоталам и форам** между **1xBet** и **Olimp**
с расчётом ставок и **проставлением в один клик**.

Это доработка исходного `arb-scanner`: парсинг стал надёжным (Olimp — через
официальный JSON-API вместо «угадывания чисел» в DOM, 1xBet — через перехват
JSON из его LiveFeed внутри залогиненного браузера), а сверху добавлена
автоматизация ставок с риск-контролями.

## Как работает

```
парсеры (1xBet, Olimp) → события {тоталы[], форы[]}
   → матчинг команд (транслит + токены + зеркальные пары)
   → поиск вилок по совпадающим линиям → расчёт ставок
   → веб-дашборд + проставление в 1 клик
```

Вилка по 2 исходам: кэф `k` ⇒ вероятность `1/k`. Surebet, когда
`1/k1 + 1/k2 < 1`; прибыль `(1/(1/k1+1/k2) − 1)·100%`; ставки делятся так, чтобы
оба исхода давали одинаковый возврат. Для тоталов/фор сравниваются только
**совпадающие линии** (ТБ 2.5 ↔ ТМ 2.5; Ф1 −1.5 ↔ Ф2 +1.5).

## Структура

```
server.js              — Express, цикл сканирования, поиск вилок, API
lib/match.js           — матчинг команд между БК (транслит, токены, reverse)
lib/arb.js             — математика вилок (индекс, прибыль, сплит ставок)
scrapers/parserOlimp.js  — Olimp через JSON-API (быстро, надёжно, без браузера)
scrapers/parser1xbet.js  — 1xBet через LiveFeed JSON в stealth-браузере
betting/coordinator.js   — риск-контроли, paper/real, история, partial-fill
betting/placer.js        — проставление кликами в залогиненном браузере
public/index.html        — дашборд: сырые данные, вилки, ставки, кнопка
test/                    — тесты (node --test)
```

## Запуск

```bash
npm install
npm start            # http://localhost:3000
npm test             # тесты
```

> ⚠️ 1xBet блокирует IP дата-центров (редирект на /block). Запускай с обычного
> IP/региона (как у тебя локально). Olimp работает отовсюду.
> Парсер 1xBet открывает браузер (`headless:false`) — на сервере нужен дисплей
> (xvfb) либо `HEADLESS=new`.

Демо без 1xBet: `DEV_FAKE_XBET=1 npm start` — «1xBet» эмулируется из данных
Olimp, чтобы посмотреть весь пайплайн (только для отладки).

## Автоставки (в 1 клик)

Кнопка «Поставить» отправляет обе ноги вилки.

- **Paper (по умолчанию):** симуляция, без денег. Безопасно.
- **Real (`BETTING_MODE=real`):** клики в твоём залогиненном браузере. Профиль
  сессии хранится в `.profile-1xbet` / `.profile-olimp` (логинишься один раз).
  Селекторы кликов калибруются один раз под реальные страницы в
  `betting/placer.js` (пока `calibrated:false` — реальная ставка не отправится).
- **Риск-контроли:** общий выключатель, мин. прибыль, макс. ставка, защита от
  повторной ставки на одну вилку.
- **Partial-fill:** если одна нога прошла, а вторая нет — статус `PARTIAL` с
  явным предупреждением (позиция не захеджирована).

### Переменные окружения

| Переменная | Назначение | По умолч. |
|---|---|---|
| `PORT` | порт сервера | 3000 |
| `SCAN_MS` | период сканирования | 5000 |
| `DEFAULT_STAKE` | банк по умолчанию | 10000 |
| `MIN_DISPLAY_PROFIT` | показывать вилки от X% | 0 |
| `ONEXBET_BASE_URL` | домен/зеркало 1xBet | https://1xbet.kz |
| `BETTING_MODE` | `paper` / `real` | paper |
| `BETTING_MIN_PROFIT` | мин. прибыль для ставки, % | 0.5 |
| `BETTING_MAX_STAKE` | лимит на ставку, ₽ | 5000 |
| `HEADLESS` | `new` для headless-браузера | — |

## Дисклеймер

Скрейпинг и автопроставление нарушают ToS букмекеров (1xBet/Olimp банят
вилочников и режут лимиты), есть риск потери денег при проскальзывании кэфов и
частичном исполнении. Только для образовательных целей, на свой риск.
